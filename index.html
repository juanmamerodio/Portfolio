Transición de Estados (DTE)

stateDiagram-v2
    [*] --> Iniciada: Inicia compra
    Iniciada --> EsperandoPago: Registran productos
    
    EsperandoPago --> Efectivo: Efectivo
    Efectivo --> Completada: Pago recibido
    
    EsperandoPago --> Tarjeta: Tarjeta
    Tarjeta --> IngresandoDNI: Solicita DNI
    IngresandoDNI --> ConsultandoAPI: DNI ingresado
    
    ConsultandoAPI --> DNI_Valido: API OK
    ConsultandoAPI --> DNI_Invalido: API Falla
    
    DNI_Valido --> ProcesandoPago: Continua
    DNI_Invalido --> ProcesandoPago: Sin edad
    
    ProcesandoPago --> PagoAprobado: Tarjeta aprobada
    PagoAprobado --> Completada
    ProcesandoPago --> PagoRechazado: Tarjeta denegada
    PagoRechazado --> EsperandoPago: Reintento
    
    Completada --> [*]
